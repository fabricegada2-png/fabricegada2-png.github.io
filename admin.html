Connexion GitHub

Le site est hébergé sur GitHub Pages : publier, c'est enregistrer content.js dans ton dépôt. Il faut pour cela un jeton d'accès GitHub. Il reste dans ce navigateur et n'est envoyé qu'à GitHub.

  1. Ouvre Créer un jeton (fine-grained).
  2. Repository access : « Only select repositories » → ton dépôt du portfolio.
  3. Permissions : Contents et Pull requests en « Read and write ».
  4. Génère le jeton, copie-le et colle-le ici.
